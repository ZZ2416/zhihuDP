# K线图与股价信息功能 — 软件需求规格说明（SRS）

> 版本：v0.1
> 日期：2026-08-16
> 状态：待评审
> 分支：`feature/kline`
> 关联文档：`business-design.md`（业务设计）、`product-design.md`（产品设计）、`tech-design.md`（技术设计）、`docs/CHANGELOG.md`

## 1. 引言

### 1.1 背景

用户搜索股票后，当前只看到「情绪面板 + AI 分析」，缺少**价格走势**这一基础信息维度。需求：搜索结果页补充**近期股价信息**与**日 K 线图**，让用户在看讨论情绪的同时能看到价格走势全貌。

### 1.2 目标

- 用户在查询任意 A 股后，能同时看到：**最新股价信息**（最新价/涨跌幅/今开/最高/最低/昨收/成交量）+ **近 60 日（默认）日 K 线蜡烛图**（含成交量）；
- 行情数据与情绪数据**互不阻塞**：K 线加载失败不影响情绪面板与 AI 分析展示。

### 1.3 范围

**包含**：
- 最新股价信息展示；
- 日 K 线蜡烛图（含成交量柱）；
- 明暗主题适配、移动端适配。

**不包含（明确不做）**：
- 实时/分时行情、多周期切换（周K/月K）、技术指标（MA/MACD/KDJ）、画线工具；
- 历史回测、下载导出；
- K 线数据进入 LLM 上下文（**合规红线**，见 §3.6）。

## 2. 总体描述

### 2.1 用户场景

场景一（主力场景）：用户输入「茅台」→ 详情页依次展示：股价信息卡（最新价+涨跌幅）→ 日K图卡 → 情绪面板 → AI 分析。
场景二（降级）：某股无 K 线数据（停牌/新股）→ 股价卡显示「暂无行情数据」，其余功能正常。

### 2.2 约束与假设

- 数据源：**东方财富公开接口**（K线 + 实时报价），免费无 key，实测可用（2026-08-16）；
- 仅支持 A 股（沪/深/北），与股票识别范围一致；
- 前复权日 K（`fqt=1`），默认 60 根，上限 250 根；
- K 线为「展示数据」，**不允许**被 agent/LLM 引用（避免模型基于价格给出买卖建议，破坏合规定位）。

## 3. 功能需求

### FR1 股价信息展示

| 项 | 内容 |
|---|---|
| 描述 | 搜索到股票后，展示最新价、涨跌额、涨跌幅、今开、最高、最低、昨收、成交量 |
| 优先级 | P0 |
| 验收 | 沪市（600519）与深市（002594）均能正确显示，涨跌幅红涨绿跌（A股惯例） |

### FR2 日 K 线蜡烛图

| 项 | 内容 |
|---|---|
| 描述 | 展示近 N 日（默认 60，可调 10–250）日 K 蜡烛图：每根蜡烛含开/收/高/低，下方成交量柱 |
| 优先级 | P0 |
| 验收 | 蜡烛颜色与涨跌一致（收盘≥开盘为红/涨，否则绿/跌）；成交量柱按量能等比缩放；坐标轴有价格刻度与日期刻度 |

### FR3 行情接口

| 项 | 内容 |
|---|---|
| 描述 | 新增 `GET /api/kline?code=&market=&days=` 接口，返回报价 + K线数组 |
| 优先级 | P0 |
| 验收 | 参数非法返回 400；数据源失败返回 502；北交所代码（如 430047）能正确映射 secid |

### FR4 加载降级

| 项 | 内容 |
|---|---|
| 描述 | K 线请求失败（网络/无数据/停牌）时，股价卡显示友好提示，**不影响**情绪面板与 AI 分析 |
| 优先级 | P1 |
| 验收 | 手动断网场景下，情绪面板与 AI 分析仍完整展示 |

### FR5 主题与响应式

| 项 | 内容 |
|---|---|
| 描述 | K 线图适配明暗主题（网格/文字/蜡烛配色随主题变化）；移动端自适应宽度 |
| 优先级 | P1 |
| 验收 | 明暗主题下图表均清晰可读；<560px 宽度下图表不溢出 |

### FR6 合规约束（红线）

| 项 | 内容 |
|---|---|
| 描述 | 行情数据**仅**用于前端展示；agent Instruction 与工具**不得**接收或引用价格数据 |
| 优先级 | P0（强制） |
| 验收 | 代码评审确认：`internal/agent` 与 `internal/sentiment` 无 kline 依赖；LLM 上下文中无价格字段 |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | `/api/kline` 端到端响应 < 1s（实测东财接口 ~300ms）；K线请求与 SSE 分析流并行（前端异步拉取，不阻塞） |
| 可靠性 | K线接口失败不 panic、不影响主流程；超时 5s |
| 可维护性 | 行情客户端独立为 dao 层包（`internal/kline`），与情绪链路解耦 |
| 安全 | 沿用现有：无新增密钥、日志脱敏、无敏感数据 |

## 5. 数据需求（东财接口契约，已实测）

### 5.1 日 K 线

```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get
  ?secid={mkt}.{code}&klt=101&fqt=1&fields1=f1,f2,f3,f4,f5,f6
  &fields2=f51,f52,f53,f54,f55,f56,f57,f58&end=20500101&lmt={days}
```
- `secid` 市场前缀：沪A=1、深A=0、北A=0
- `klines[]` 格式：`日期,开盘,收盘,最高,最低,成交量(手),成交额,振幅%`
- 响应含 `preKPrice`（昨收）、`decimal`（小数位）、`name`

### 5.2 实时报价

```
GET https://push2.eastmoney.com/api/qt/stock/get?secid={mkt}.{code}&fields=f43,f44,f45,f46,f47,f48,f60,f169,f170,f171
```
- `f43`=最新价(÷100)、`f44`=最高、`f45`=最低、`f46`=今开、`f47`=成交量、`f60`=昨收、`f169`=涨跌额(÷100)、`f170`=涨跌幅%(÷100)、`f171`=振幅%(÷100)

## 6. 边界与异常处理

| 场景 | 处理 |
|---|---|
| 停牌/新股无K线 | 返回空 candles，前端显示「暂无行情数据」 |
| 北交所代码 | secid 映射 `北A→0`，实测验证 |
| `days` 越界 | clamp 到 [10, 250]，默认 60 |
| 接口超时/非200/JSON异常 | 返回明确错误，前端降级卡片 |
| 代码/市场参数缺失 | 400 |

## 7. 验收标准

| # | 验收项 | 通过标准 |
|---|---|---|
| 1 | 接口连通 | `/api/kline?code=600519&market=沪A&days=60` 返回合法 JSON（quote + 60 根 candles） |
| 2 | 数据正确 | 报价字段与东财页面一致；K线日期连续、开收高低关系正确（高≥开收≥低） |
| 3 | 前端渲染 | 浏览器展示蜡烛图 + 成交量 + 股价卡，明暗主题均正常 |
| 4 | 降级 | 断网/非法代码时情绪面板与 AI 分析不受影响 |
| 5 | 合规 | `internal/agent`、`internal/sentiment` 无行情数据引用（代码评审） |
