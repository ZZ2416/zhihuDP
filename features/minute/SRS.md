# 当日分时图（K线图内切换）— 需求规格（SRS）

> 版本：v1.0（已实现）· 日期：2026-08-19 · 分支：`feature/minute`

## 1. 背景与目标

在详情页 K 线图上方提供「**日K / 分时**」切换：查看个股当日分时走势（价格线 + 均价线 + 昨收参考线），与主流行情软件一致。

## 2. 功能需求

| # | 需求 | 优先级 | 验收 |
|---|---|---|---|
| FR-M1 | K 线图上方「日K / 分时」切换按钮（共用一块图） | P0 | 按钮可切换，激活态高亮 |
| FR-M2 | 分时图：价格折线（涨红跌绿）+ 均价线 + 昨收虚线 + 右上角涨跌幅 + 底部时间刻度 | P0 | 渲染完整，数据真实 |
| FR-M3 | 数据源**东财主 + 腾讯兜底**（用户确认双源） | P0 | 主失败自动切腾讯 |
| FR-M4 | 懒加载 + 缓存：点「分时」才请求；切回日K 用缓存重画（不重复请求） | P1 | 切换流畅无重复请求 |
| FR-M5 | 切股重置：搜索新股票后分时缓存清空、回到日K | P1 | 新股票分时重新加载 |
| FR-M6 | 加载失败友好提示（「分时加载失败，请稍后重试」） | P1 | 失败不阻塞页面 |

## 3. 数据契约（实测 2026-08-19）

| 接口 | 说明 | 实测 |
|---|---|---|
| 东财 `push2his.eastmoney.com/api/qt/stock/trends2/get`（主） | 241 点/日，含均价、昨收 preClose | ✅ 茅台 121 点（上午） |
| 腾讯 `web.ifzq.gtimg.cn/appstock/app/minute/query`（兜底） | 分钟数据，无均价 → 累计均价 | ✅ |

## 4. 验收

| # | 项 | 标准 |
|---|---|---|
| 1 | 接口 | `/api/minute?code=600519&market=沪A` 返回 points[]（time/price/avg_price/volume）+ pre_close |
| 2 | UI | 切换按钮 + 分时渲染（价格/均价/昨收线） |
| 3 | 双源 | 东财失败自动切腾讯（degraded=true） |
| 4 | 回归 | 日K 渲染、十字光标交互不受影响 |
