# B站相关视频（按最近时间/播放量排序）— 需求规格（SRS）

> 版本：v1.0（已实现）· 日期：2026-08-19

## 1. 背景与目标

传入股票信息（股票名），获取该股相关的**视频资讯**，**按最近时间和播放量排序**展示。

**数据源调研结论（实测）**：抖音 web 搜索需 a_bogus 签名（反爬强、易失效、法律风险）；B站 wbi 签名公开简单、字段齐全 → 用户确认**改 B站**。

## 2. 功能需求

| # | 需求 | 优先级 | 验收 |
|---|---|---|---|
| FR-V1 | 详情页新增「相关视频」卡片（B站，标题可点击跳转） | P0 | 搜索个股后卡片显示视频列表 |
| FR-V2 | **按最近时间 / 播放量排序**（前端排序切换按钮） | P0 | 点「最新」按发布时间降序、点「播放量」按播放降序 |
| FR-V3 | 字段：标题（清洗高亮标签）/播放量/发布时间/时长/UP主/链接 | P0 | 8 条真实数据 |
| FR-V4 | 数据源：B站 wbi 签名搜索接口（实测可用） | P0 | 接口返回真实数据 |
| FR-V5 | 加载失败友好降级 | P1 | 失败显示提示不阻塞 |
| FR-V6 | 切股重置 | P1 | 新股票重新加载 |

## 3. 数据契约（B站 wbi 搜索，实测 2026-08-19）

- `GET /x/web-interface/nav` → `wbi_img.img_url/sub_url`（**未登录 code=-101 但密钥仍返回**）
- `GET /x/web-interface/wbi/search/type?keyword=&search_type=video`（wbi 签名：img/sub key → mixin key → 参数+wts 排序+md5）
- 字段：title（含 `<em>` 高亮需清洗）、bvid、play、video_review、duration（**mm:ss 字符串**，非秒）、pubdate（时间戳）、author

## 4. 验收

| # | 项 | 标准 |
|---|---|---|
| 1 | 接口 | `/api/video?keyword=贵州茅台&count=8` 返回 8 条真实视频 |
| 2 | 排序 | 前端「最新 / 播放量」切换生效 |
| 3 | 字段 | 时长 mm:ss、播放量、发布时间、链接可点 |
| 4 | 回归 | 其他功能不受影响；build/vet/test 全绿 |
