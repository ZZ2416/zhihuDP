# 二期 · 看山追问对话（AI 看山 Agent）— 需求规格（SRS）

> 版本：v0.2（决策已定稿）· 日期：2026-08-16 · 分支：`v2_chat`（规划）
> 前置：一期已上线（个股识别 → 行情/情绪/AI 分析）

## 1. 背景与目标

一期：用户搜索个股 → 输出价格/K线、知乎情绪面板、AI 分析（一次性结论）。

二期目标：用户对一期结果有疑问时，可**继续追问**——agent 基于「已得出的内容」（情绪面板、知识库、前次分析，可选行情快照）结合用户新提问**多轮对话给建议**。agent 以 **「AI 看山」** 人设回答（口吻 + 界面标识）。

**合规红线（延续并强化）**：不推荐具体股票、不给买卖结论、无「概率」类措辞；建议尺度限定为**方法 / 维度 / 风险提示**。

## 2. 功能需求

| # | 需求 | 优先级 | 验收 |
|---|---|---|---|
| FR-V1 | **独立对话面板**：详情页 **K 线面板下方**「与看山对话」对话区（独立聊天窗口，与股票详情分开，不覆盖主内容） | P0 | 详情页 K线下方可见对话区；可清空会话 |
| FR-V2 | **多轮追问**：面板内连续提问，上下文记忆（当前股票 + 历史消息） | P0 | 追问「那情绪为什么会偏空」能结合上一轮上下文回答 |
| FR-V3 | **AI 看山人设**：系统提示词定义身份（刘看山）、口吻、行为边界；面板与 AI 分析区配看山头像/标识 | P0 | 回答以看山口吻；界面有看山标识 |
| FR-V4 | **上下文注入**：对话时携带 ①当前股票信息 ②情绪面板结果 ③知识库检索片段 ④前次 AI 分析文本（⑤行情快照，见 §5 开放问题） | P0 | 追问涉及情绪/讨论时回答基于真实数据，非凭空 |
| FR-V5 | **合规过滤**：对话回复复用一期 compliance 过滤（禁荐股、禁概率词、禁买卖结论） | P0 | 人为诱导「该买吗」时拒绝并给方法/风险提示 |
| FR-V6 | **流式回复**：SSE 增量输出（复用一期 delta 机制） | P1 | 打字机效果，可中断/重试 |
| FR-V7 | 对话**失败降级**：LLM 异常时提示重试，不阻塞页面其他功能 | P1 | 断网/超时给出友好错误 |
| FR-V8 | 面板内**清空/新会话**；切换股票后会话上下文重置为新股（保留历史会话可回看，P2 可选） | P2 | 有清空按钮；切股后不串上下文 |

## 3. 业务规则

### 3.1 AI 看山人设（skill：ai_kanshan）
- **身份**：知乎吉祥物刘看山（北极狐），自称「看山」；
- **口吻**：温和、拟人、带一点点俏皮，但**专业克制**；多用「看山觉得 / 看山注意到」；
- **边界**：明确自己是信息工具助手，不做投资决策；被问「买/卖/抄底」时，用方法+风险提示回应并说明不荐股；
- **人设载体**：Agent system prompt（二期新增 `internal/agent` 人设模板）+ 界面头像/开场文案。

### 3.2 合规边界（建议尺度）
| 允许（方法/维度/风险） | 禁止（红线） |
|---|---|
| 分析方法：如何看情绪分布、如何读 K 线形态 | 推荐/暗示具体股票买卖 |
| 关注维度：现金流、估值分位、仓位管理原则 | 「该买」「该卖」「抄底」「加仓」结论 |
| 风险提示：情绪过热、波动放大、信息面 | 「概率」「胜率」等预测性措辞 |
| 知识库方法论复述（知乎「股票投资方法论」） | 目标价、收益承诺 |

### 3.3 上下文范围（对话时注入 LLM）
- ✅ 注入：股票名称/代码/板块、**行情快照**（当前价、涨跌幅、今开/最高/最低、成交量——报价级事实）、情绪面板结果（heat/ratio/score/items 摘要）、知识库检索片段、前次 AI 分析文本、对话历史
- ❌ 不注入：完整 K 线序列、资讯、热门榜（一期红线延续；对话需结合行情的场景由行情快照覆盖）

## 4. 交互流程（时序）

```
用户：搜索「茅台」→ 一期 /api/ask（行情+情绪+AI 分析）
用户：点击「与看山对话」→ 打开独立对话面板（带看山头像）
用户：追问「情绪为什么偏空？」→ POST /api/chat
  ├─ 服务端组装上下文：股票 + 情绪快照 + 知识库片段 + 前次分析 + 历史
  ├─ 人设 system prompt + 合规约束
  └─ SSE 流式返回看山回答（delta → done）
用户：继续追问（多轮，同一会话）→ 上下文累加
```

## 5. 接口契约（草案，SDD 细化）

```
POST /api/chat                      # 二期新增：追问对话（SSE）
  body: { "stock": "600519", "session_id": "…", "message": "情绪为什么偏空？" }
  resp(SSE): event: delta {text} → event: done / error

POST /api/chat/session              # 新建/清空会话（或并入 /api/chat 参数）
GET  /api/chat/history?session_id=  # 历史回看（P2 可选）
```

## 6. 非功能需求

- 合规过滤为硬约束：对话输出**必须**过 compliance 过滤（与一期同链路）
- 上下文长度控制：知识库片段截断 + 历史消息窗口（如最近 10 条），防超 token
- 面板与详情互不阻塞；SSE 断连可重试
- 行情/资讯/热门展示数据不进 LLM 的一期红线，仅按 §3.3 有限例外
