# 财报爬取 + AI 解析 — 需求规格（SRS）

> 版本：v1.0（已实现）· 日期：2026-08-17 · 分支：`feature/finance`
> 依据：`features/finance/设计方案.md`

## 1. 背景与目标

搜索个股后，详情页新增「**财务解析**」卡片：抓取该公司核心财务指标（最新报告期 + 5 年年报），用 **AI 流式解读**盈利质量、成长性、财务健康与风险——**只做财务状况解读，不荐股**（合规红线延续）。

## 2. 功能需求

| # | 需求 | 优先级 | 验收 |
|---|---|---|---|
| FR-F1 | 详情页新增「财务解析」卡片（**情绪面板上方**，用户确认） | P0 | 搜索个股后卡片显示指标表格 + AI 解析 |
| FR-F2 | 指标范围：营收/净利/ROE/毛利率/净利率/负债率/每股收益/经营现金流等，**最新报告期 + 最近 5 年年报** | P0 | 600519 返回 6 期真实数据 |
| FR-F3 | AI 解析五段式：盈利能力/成长性/财务健康/值得关注的指标/风险提示（SSE 流式，**自动触发**） | P0 | 流式输出，数据基于注入指标 |
| FR-F4 | 数据源**东财主 + 兜底**（datacenter 主、F10 兜底；腾讯财务实测不可用） | P0 | 主失败自动切兜底并置 degraded |
| FR-F5 | 合规：输出过过滤，不荐股/不评股价/无概率词，文末免责 | P0 | 诱导「该买吗」→ 拒绝 + 风险提示 |
| FR-F6 | 加载失败友好降级（「暂不可用 + 重试」），不阻塞其他功能 | P1 | 断网时财务卡片降级，其余正常 |
| FR-F7 | **「与看山对话」上下文加入财报指标**（用户确认）：可追问「负债率为什么这么低」等 | P1 | 追问财务问题基于真实指标回答 |
| FR-F8 | `POST /api/finance/analyze` 计入会话配额（与 ask/chat 共享 20 次/页） | P1 | 超配额 403 |

## 3. 数据契约（东财实测 2026-08-17）

| 接口 | 用途 | 实测 |
|---|---|---|
| `datacenter.eastmoney.com/.../RPT_F10_FINANCE_MAINFINADATA`（主） | 年报过滤 + 排序，`SECUCODE=600519.SH` | ✅ 6 期真实数据 |
| `emweb.../ZYZBAjaxNew`（兜底） | F10 页面接口，141 字段 | ✅ |
| 腾讯财务（多端点） | — | ❌ 不可用（F10Controller 不存在） |

## 4. 验收

| # | 项 | 标准 |
|---|---|---|
| 1 | 接口 | `/api/finance?code=600519` 返回 6 期指标（营收亿元、ROE、毛利率、负债率…） |
| 2 | AI | `/api/finance/analyze` SSE 流式五段解读，含免责 |
| 3 | 合规 | 无买入/概率词；诱导「该买吗」拒绝 |
| 4 | 降级 | 双源失败 → 友好提示 + 重试 |
| 5 | 回归 | /api/ask、/api/chat、密钥、媒体播放不受影响 |
