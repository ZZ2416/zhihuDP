# 设计方案：财报爬取 + AI 解析（features/finance）

> 版本：v0.1 · 日期：2026-08-17 · 分支：`feature/finance`（规划）
> 决策（用户确认）：详情页内嵌「财务解析」卡片 · 核心财务指标 3-5 年趋势 · 东财主 + 兜底

---

## 1. 目标与范围

搜索个股后，详情页新增**「财务解析」卡片**：抓取该公司**核心财务指标**（营收/净利/ROE/毛利率/净利率/负债率/现金流等，最近 5 年年报趋势），用 **AI 解读**盈利质量、成长性、财务健康与风险——**只做财务状况解读，不荐股**（合规红线延续）。

## 2. 数据源实测结论（2026-08-17 实测）

```

├── 实时行情 / K线（现有）
├── 情绪面板（现有）
├── 【新增】财务解析卡片
```

- 加载失败（东财双源都挂）→ 卡片显示「财务数据暂不可用 + 重试」，不阻塞其他功能（沿用友好降级策略）
- 数据源为展示数据；AI 解析基于注入的指标文本生成，**指标数值不进对话 SSE 之外的其他通道**

## 5. AI 解析设计

### 5.1 请求流程
```
GET /api/finance?code=&market=  → 指标数据（前端渲染表格 + 暂存）
POST /api/finance/analyze {code, market}（SSE）
  ├─ 服务端拉取指标 → 格式化文本（注入 LLM）
  ├─ 财务解析 prompt（只基于注入指标，不编造）
  └─ 流式 delta → done / error（复用 compliance 过滤）
```

### 5.2 财务解析 prompt 骨架
```
你是财务分析助手。基于下方提供的公司财务指标（最近5年年报+最新报告期），输出解析：
1. 盈利能力与质量：毛利率/净利率/ROE 水平与趋势；
2. 成长性：营收/净利同比与 5 年趋势；
3. 财务健康：资产负债率、经营现金流；
4. 值得关注的指标变化（同比波动 >20% 的项重点说明）；
5. 风险提示。
约束：只基于给定数据；不推荐买卖、不评价股价、不用「概率/预测」措辞；数据不足时如实说明。
```

### 5.3 合规
- 财务指标（公司基本面事实）**允许进入 LLM**——与一期「行情/资讯不进 LLM」不冲突：行情是实时价格（与投资决策强相关），财报是公开财务事实（解析对象本身）
- 输出过 compliance 过滤（禁荐股/概率词），文末注明「数据来源东方财富，不构成投资建议」

## 9. 风险与开放问题

1. **东财接口稳定性**：ZYZBAjaxNew 是页面接口（非公开 API），可能变动/限流——双接口互备 + 友好降级兜底；数据源标注「东方财富」
2. **字段口径**：ROE 取加权（ROEJQ）、净利率取销售净利率（XSJLL）；同比为单季/累计口径差异需在表格标注
3. **AI 解析速度**：5 年年报文本化后 token 适中（~1-2k），流式输出可控
4. **财报数据进对话**：二期「与看山对话」是否把财务指标加入上下文（用户可追问「负债率为什么这么低」）——默认加入（与行情快照同级，最小事实注入），SDD 细化
