# 首页热门推荐 + 看山吉祥物主题 — 需求规格（SRS）

> 版本：v0.1 · 日期：2026-08-16 · 分支：`ui_premiu`

## 1. 背景与目标

1. 首页除搜索外，增加**热门股票推荐**与**热门板块推荐**，让用户打开即见市场热点，一键点击查询；
2. 接入**看山（刘看山）吉祥物**素材（`pic/` 目录），主题化界面；
3. 交互风格对标「看山指数」终端页（ticker 滚动条 + 网格工作区），**保留现有双主题与全部功能**。

## 2. 功能需求

| # | 需求 | 优先级 | 验收 |
|---|---|---|---|
| FR-U1 | 首页展示**热门板块**（6 个，涨幅榜，实时） | P0 | 打开首页显示板块名 + 涨幅，点击可查询该板块内热门股（或提示） |
| FR-U2 | 首页展示**热门股票**（8 只，涨幅榜，实时） | P0 | 显示股票名/代码/涨幅，**点击直接查询该股**（走现有 /api/ask） |
| FR-U3 | 热门数据为**展示数据，不进 LLM**（合规，同 K线/资讯策略） | P0 | agent/sentiment 无 hot 依赖 |
| FR-U4 | 看山吉祥物素材用于首页/页头（hero 区装饰） | P1 | 首页显示吉祥物图（明暗主题均可见） |
| FR-U5 | 终端风格交互：ticker 滚动条 + 网格面板布局 | P1 | 顶部滚动条展示热门股票，详情区网格化 |
| FR-U6 | 热门数据加载失败静默降级（不阻塞搜索） | P1 | 断网时首页仍可搜索 |

## 3. 数据契约（东财 clist，已实测 2026-08-16）

### 热门股票（沪深A股涨幅榜）
```
GET https://push2.eastmoney.com/api/qt/clist/get
  ?pn=1&pz={count}&po=1&np=1&fltt=2&invt=2&fid=f3
  &fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23,m:0+t:81+s:2048
  &fields=f2,f3,f12,f14
```
- `data.diff[]`：`f12`=代码、`f14`=名称、`f2`=最新价、`f3`=涨跌幅%

### 热门板块（行业板块涨幅榜）
```
GET https://push2.eastmoney.com/api/qt/clist/get
  ?pn=1&pz={count}&po=1&np=1&fltt=2&invt=2&fid=f3&fs=m:90+t:2
  &fields=f2,f3,f12,f14
```
- `data.diff[]`：`f14`=板块名、`f3`=涨幅%、`f12`=板块代码
