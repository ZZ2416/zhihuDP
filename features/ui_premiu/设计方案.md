# 首页热门推荐 + 看山吉祥物主题 — 设计方案

> 版本：v0.2 · 日期：2026-08-16 · 分支：`ui_premiu`
> 定位：产品/UX 设计方案（先设计后实现；当前实现进度见文末 §8）

---

## 1. 设计目标与原则

| 目标 | 说明 |
|---|---|
| 打开即见热点 | 首页首屏展示市场热门，用户无需输入即可浏览、一键查询 |
| 吉祥物品牌化 | 接入知乎官方看山（刘看山）素材，强化「知乎系」识别 |
| 终端风格交互 | 交互形态对标「看山指数」热力终端：ticker 滚动条 + 网格面板 + 大字号排版 |
| 不破坏现有 | 保留明暗双主题、搜索/SSE/K线/情绪/资讯全部功能 |

**设计原则**：信息优先（热点数据最先可见）、渐进增强（热门加载失败不阻塞搜索）、合规克制（热门数据仅展示，不进 LLM）。

## 2. 用户与场景

| 场景 | 描述 |
|---|---|
| 场景一（浏览热点） | 用户打开首页 → 看到 ticker 滚动 + 热门板块/股票 → 点击感兴趣的直接查询 |
| 场景二（精准查询） | 用户输入股票名/代码 → 走原有搜索链路 |
| 场景三（降级） | 热门数据失败 → 首页只剩搜索，功能不受影响 |

## 3. 信息架构

```
首页
├── 顶栏：Logo + 主题切换
├── ticker 行情条（热门股票，可点击）
├── hero：看山吉祥物 + 标题 + 副题
├── 搜索卡片（输入 + 联想）
├── 热门板块卡片（chips，仅展示）
└── 热门股票卡片（列表，点击查询）
    │
    └──（点击）→ 详情页
详情页
├── 股票信息卡
├── 实时行情卡（报价 + K线图，可交互）
├── 情绪面板卡
├── AI 分析卡（流式）
└── 相关资讯卡（仅参考，不跳转）
```

## 4. 首页设计

### 4.1 ticker 行情条

- 位置：顶栏下方、全页可见（终端页标志性组件）
- 内容：热门股票（名称 + 涨跌幅，红涨绿跌）
- 交互：横向滚动（`overflow-x:auto`，触摸可滑）、点击某项 → 直达查询
- 数据：`/api/hot?type=stock`，加载失败 → 隐藏

### 4.2 hero 区

- 看山吉祥物图（`web/pic/kanshan.png`，圆角卡片 + 阴影，明暗主题均可视）
- 大标题 + 副题（clamp 响应式字号，terminal 感）

### 4.3 热门板块（chips）

- 6 个行业板块 chip：板块名 + 涨幅%（红涨绿跌）
- 交互：**仅展示**（板块内成分股查询为 P1 后置，见 §7 待确认）

### 4.4 热门股票（列表）

- 8 只涨幅榜：名称 / 代码 / 最新价 / 涨幅
- 交互：**点击 → 输入框赋值 + 触发查询**（复用现有 doSearch 链路）

## 5. 详情页设计

保持现有结构（股票信息 → 行情/K线 → 情绪 → AI 分析 → 资讯），不做结构性改动；终端风格体现为：ticker 常驻顶部 + 面板卡片化排版。

## 6. 看山吉祥物使用规范

| 位置 | 素材 | 尺寸/样式 |
|---|---|---|
| 顶栏 Logo | SVG 鲸鱼（现有） | 34×30，accent 色 |
| 首页 hero | `pic/kanshan.png`（四视图） | 120px 宽，圆角 + 边框 + 阴影 |
| （备用） | `pic/kanshan-hero.jpg`（三视图） | 未来 hero 大图/页脚装饰用 |

- 明暗适配：素材本身白底 → 外层卡片用 `var(--card)` + 边框，避免亮暗反差刺眼
- 版权：看山为知乎官方吉祥物，本项目为知乎内部/个人 demo 使用，勿外链商用

## 7. 主题策略

- **保留明暗双主题**（CSS 变量体系不变，不引入第三主题）
- 终端风格通过「布局与交互」体现（ticker、面板、字号），而非新配色
- 新增组件（ticker/hot 卡片）全部使用现有 `--accent/--bull/--bear/--card/--border` 变量，自动适配双主题

## 8. 验收标准

| # | 项 | 标准 |
|---|---|---|
| 1 | 首页热点 | 打开首页可见 ticker + 热门板块 + 热门股票（实时数据） |
| 2 | 点击查询 | 点击热门股票 → 进入该股详情全链路（行情/情绪/AI） |
| 3 | 吉祥物 | 首页可见看山素材，明暗主题均可读 |
| 4 | 双主题 | 新增组件在明暗主题下均正常 |
| 5 | 降级 | 热门加载失败不影响搜索 |
| 6 | 合规 | 热门数据不进 LLM 上下文 |
